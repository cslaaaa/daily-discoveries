# 每日实用发现

只保存用于博客“发现”栏目的公开推荐，不包含博客源码或私人资料。

## 内容规则

- 每天北京时间 08:00 开始搜索与筛选，完成后发布；通常精选 3–5 条，宁缺毋滥。
- 优先成熟、实用、能减轻负担或帮助理解的资源，跨领域轮换，不追热点，不重复凑数。
- 每条简短说明名称、用途、必要费用或限制、可信原始链接；需要时补一句开始方法。
- 核实功能、链接与费用；区分实际可用功能和演示，不编造使用体验。
- 聊天与博客使用同一组推荐。公开内容不得包含私人背景、聊天记录、源码、凭据或密钥。
- 沿用博客现有主题和卡片，首页展示最新内容，历史按日期保留，不擅自增加界面功能。
- 同日期幂等发布；失败保留旧内容，不以空白覆盖，不把未经验证的更新标为成功。
- 仅搜索、整理和发布推荐，不自动安装、注册、购买或改变系统；新增权限另行确认。

## 发布状态

本仓库是公开内容源。仓库写入不等于网站发布成功，网站更新须经过接收校验和实际读回验证。
